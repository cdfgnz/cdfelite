## 🚀 Welcome to cdfelite!

Football isn’t just a game—it’s a world of numbers, patterns, and hidden insights. **cdfelite** is designed to bypass endless, chaotic spreadsheets and deliver clear, elite-level data visualization and modeling. Whether you are identifying under-23 talent or benchmarking elite players, this is your ultimate analytics hub.

---

## 🔍 Core Features & Modules

### 📊 1. Stats Dashboard
* Visualize top performers across multiple global leagues.
* Filter dynamically by age, nationality, position, or team.
* Compare up to 3 stats simultaneously using interactive 2D or **3D Scatter Charts**.

### ⚖️ 2. Player Comparison
* Side-by-side performance benchmarking using **Per 90 metrics** or **Percentile Rankings**.

### 🍕 3. Player Scout Report
* Automated generation of detailed positional profiles.
* Includes customizable **Percentile Pizza Charts** categorized by position, role, or league standard with auto-watermarks.

### 🧬 4. Player Clone (Similarity Engine)
* Find players with highly similar statistical profiles based on selected key attributes.

### 🕵️‍♂️ 5. Player Profiler & Performance Index
* **Role Profiling:** Identify the most suitable modern tactical role for any player.
* **Custom Index:** Discover talent based on curated performance scores (Attacking, Pressing, Playmaking).

---

## 🛠️ Tech Stack & Data Architecture

* **Frontend Framework:** Streamlit
* **Data Processing:** Python (`pandas`, `numpy`, `scipy`)
* **Data Visualization:** `matplotlib`, `mplsoccer`, `plotly`
* **Data Integration:** Automated live pipelines synced with **FBref** (Opta data).
